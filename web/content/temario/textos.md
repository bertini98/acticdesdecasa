# Formato y estructura

- Un **salto de página** hace que el texto siga en la página siguiente, aunque la actual no esté llena. Es mucho mejor que pulsar Intro muchas veces: si cambias el texto, no se descoloca.
- Usa **estilos** (Título 1, Título 2…) para dar formato coherente y poder crear un índice automático.

# Combinación de correspondencia

Sirve para crear **cartas o documentos personalizados** a partir de una lista de datos. Escribes una carta modelo con campos como «Nombre», y se genera una copia para cada persona de la lista.

# Formatos de archivo

- `.docx` / `.odt`: documentos editables.
- `.pdf`: **conserva el formato**, las fuentes y las imágenes en cualquier dispositivo. Ideal para enviar o imprimir.
- `.txt`: solo texto, sin formato.

# Formato básico

- **Fuente**: el tipo de letra. **Negrita, cursiva y subrayado** para destacar.
- **Alineación**: izquierda, centrada, derecha o **justificada** (a ambos márgenes).
- **Márgenes**: espacio en blanco entre el texto y el borde del papel.
- **Corrector ortográfico** y **Buscar y reemplazar** (cambia una palabra en todo el documento).

# Nivel medio

- **Sangría**: desplaza el texto respecto al margen (por ejemplo, la primera línea del párrafo).
- **Interlineado**: espacio entre las líneas (sencillo, 1,5, doble).
- **Encabezado y pie de página**: se repiten en todas las páginas.
- **Notas al pie**: aclaraciones numeradas al final de la página.
- **Orientación**: vertical u horizontal (apaisada).
- **Salto de página** (seguir en la siguiente) y **salto de sección** (partes con distinto formato).
- **Control de cambios**: ver, aceptar o rechazar las modificaciones de otras personas.

# Nivel avanzado

- **Estilos de título** → **índice automático** que se actualiza solo.
- **Número de página como campo**: se actualiza al añadir o quitar páginas.
- **Referencias cruzadas** («ver figura 3») que se actualizan solas.
- **Plantillas**: documentos base para reutilizar.
- Guardar como **.txt** pierde el formato y las imágenes; para que otros editen, envía **.docx/.odt**; para que nadie lo cambie, **.pdf**.
