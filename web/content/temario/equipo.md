# Partes del ordenador

- **Periféricos de entrada:** envían datos al ordenador (teclado, ratón, micrófono, escáner).
- **Periféricos de salida:** muestran o sacan información (monitor, impresora, altavoces).
- **Memoria RAM:** guarda lo que estás usando ahora mismo. Es **temporal**: se vacía al apagar el ordenador. Por eso hay que guardar el trabajo.
- **Almacenamiento** (disco duro, SSD, memoria USB): conserva los archivos aunque apagues.

# Archivos y carpetas

- La **extensión** indica el tipo de archivo: `.docx` texto, `.jpg`/`.png` imagen, `.mp3` audio, `.mp4` vídeo, `.pdf` documento.
- **Copiar** duplica el archivo; **cortar** lo mueve (desaparece de su sitio original).
- **Guardar como** guarda una copia con otro nombre o en otra carpeta, sin tocar el original.
- Lo que eliminas en Windows va a la **Papelera de reciclaje**, desde donde aún puedes recuperarlo.

# Atajos de teclado básicos

- `Ctrl + C` copiar · `Ctrl + V` pegar · `Ctrl + X` cortar · `Ctrl + Z` deshacer.
- **Retroceso** borra el carácter a la izquierda del cursor; **Supr**, el de la derecha.

# Conceptos básicos

- **Hardware**: las piezas físicas (pantalla, teclado, disco, memoria). **Software**: los programas.
- **Sistema operativo**: el programa principal que gestiona el ordenador y permite usar los demás (Windows, macOS, Linux; Android o iOS en móviles).
- **Unidades de almacenamiento**, de menor a mayor: KB → MB → GB → TB. Cada una es unas mil veces la anterior.
- **Pendrive (memoria USB)**: almacenamiento portátil para llevar archivos.

# Manejo del ordenador

- **Escritorio**: la pantalla principal con iconos, barra de tareas y botón de inicio.
- **Ratón**: clic para seleccionar, doble clic para abrir, clic derecho para el menú contextual. **Arrastrar y soltar**: mover un elemento manteniendo pulsado el botón.
- **Alt + Tab**: cambiar entre ventanas abiertas.
- **Mayús + letra** escribe una mayúscula; **Bloq Mayús** deja todo en mayúsculas.

# Atajos que conviene saber

- `Ctrl + C` copiar · `Ctrl + X` cortar · `Ctrl + V` pegar
- `Ctrl + Z` deshacer · `Ctrl + Y` rehacer
- `Ctrl + P` imprimir · `Ctrl + F` buscar
- `Alt + Tab` cambiar de ventana

> Copiar duplica; cortar mueve. Lo que eliminas va a la Papelera y se puede recuperar.
